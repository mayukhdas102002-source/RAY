# Shot card

| Field | Value |
|---|---|
| Shot | S__ · <name> · <start–end> (<length>s) |
| Beat | What changes in the story here |
| Job | Change emotion / advance action / raise pressure (if none, cut the shot) |
| Message | What the viewer learns (feature in **bold**) |
| Frame | Wide / medium / close / insert · lens (24/35/50/85mm) |
| Composition | Where the eye lands in the first 0.3s · safe area |
| Camera | ONE move + its reason ("slow push-in as she reads") |
| Action | The exact physical event, plus its consequence |
| Performance | 2–4 physical cues (no named emotions) |
| Light | Source, direction, quality (motivated) |
| Environment pressure | One physical fact that carries the mood |
| Sound | Dialogue (exact line), SFX, music, bridge into the next shot |
| UI layer | Remotion screen / super / display, or "none" |
| Cut in / out | Cut on action / match / J-cut / sound bridge |
| Maker · model | AI / Remotion / effect · <model> · generate <n>s, keep <n>s |
| Refs to attach | Character sheet, set sheet, previous frame |
| Keyframe prompt | … |
| Motion prompt | … |
| Risk | Known tell for this shot (hands, walk, reflection) and the mitigation |
