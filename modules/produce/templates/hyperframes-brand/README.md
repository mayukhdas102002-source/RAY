# HyperFrames brand starter

HTML + GSAP compositions rendered to video by `npx hyperframes` (Apache-2.0, Node 22+, system FFmpeg).

## Two ways to build

**Templated (fast, on-brand baseline)**
```bash
python <skill>/scripts/timeline_from_vo.py ../scenes.json --hyperframes .   # timeline.json, transcript.json, assets/vo
python <skill>/scripts/hf_build.py . --size 1920x1080                       # index.html
python <skill>/scripts/hf_build.py . --size 1080x1920 --into ../hyperframes-9x16   # one root index.html per project
npx hyperframes lint
npx hyperframes preview            # http://localhost:3002, show the user, wait for approval
npx hyperframes render --quality draft -o renders/draft.mp4
npx hyperframes render --quality delivery -o renders/final.mp4      # only after approval
```

**Atelier (hero / launch work)**: hand-author `index.html` and `compositions/*.html` against `brand.css` and `frame.md`.
Read `references/hyperframes.md` in the skill first. Search the catalog before writing any named effect:
`npx hyperframes catalog --query "logo reveal" --json`, then `npx hyperframes add <block>`.

## Files
- `brand.css`: generated by `brand_tokens.py` (CSS variables + `@font-face`). Never hand-edit; change `brand/brand.json`.
- `frame.md`: the HyperFrames design spec for this brand (tokens + prose). Agents read it before authoring.
- `timeline.json` / `transcript.json`: the locked master clock and VO words. Re-run `timeline_from_vo.py` after any VO change.
- `compositions/brand-lower-third.html`: example sub-composition (template-wrapped, id-prefixed, one timeline).
- `assets/`: `vo/`, `audio/`, `media/`, `brand/` (fonts, logos). Reference local files only.

## Contract (do not break)
- Root: `data-composition-id`, `data-width`, `data-height`, `data-duration` (seconds). No `<template>` in index.html.
- Timed elements: `data-start`, `data-duration`, `data-track-index`; visible divs get `class="clip"`; never put `clip` on `<video>`/`<audio>`.
- Every `<audio>` needs an `id`. `<video>` is `muted playsinline`; animate a wrapper, not the video.
- One paused GSAP timeline per composition: `window.__timelines["<id>"] = tl`, registered synchronously.
- Deterministic only: no `Math.random`, `Date.now`, render-time `fetch`, `repeat: -1`, CSS transitions.
- Entrances on every scene (`fromTo`); no exit animations except the final scene; the transition is the exit.
- Never tween `visibility`/`display`/`autoAlpha` on a `.clip`; animate a child.
- Parallel workers can paint video layers black: use `--workers 1` when the composition has `<video>`.
